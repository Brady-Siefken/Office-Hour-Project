This was a group project made for a class in Spring of 2026. It utilizes Python, Django, HTML, and CSS. It's purpose is for Instructors and TAs to set office hours
for their classes and for students to reserve. The project wasn't fully finished, as that was not the goal of the project. 

Currently, after manually creating an admin user, the app can create Instructor, TA, and Student users, can create classes with timeslots, can assign Instructors and 
TAs to classes, assign classes to students, can create office hours for classes, can view office hours, and students can reserve office hours. Instructors can create
students by pasting their emails and names when adding students to a course. After a scheduled office hour has been passed, the instructor or TA can mark the student
as tardy or a no-show. 

While the app runs nicely, there might be some dead code we wrote at the beginning of the project that we forgot to clean up.
